# CodexBar

Check your coding-assistant usage quotas directly from Raycast. CodexBar wraps the external
`codexbar` CLI and renders a usage overview — meters, pacing, and incident status — for every
provider you have configured.

## Requirements

The [`codexbar` CLI](https://github.com/steipete/CodexBar) must be installed (Homebrew or a GitHub
release). The CodexBar macOS app is optional — the CLI can run standalone.

## Contributing

See [`docs/`](docs/) — start with [`docs/maintaining.md`](docs/maintaining.md). This extension mirrors
the upstream CodexBar app, so keeping parity is most of the work; [`docs/upstream-parity.md`](docs/upstream-parity.md)
is required reading before changing provider metadata, pacing, or icons.
